使用手冊

四象限矩陣

Q1 — 緊急且重要立即處理，優先度最高
Q2 — 重要不緊急規劃時間處理，長期投資
Q3 — 緊急不重要可委派他人處理
Q4 — 不緊急不重要低優先，考慮刪除

任務操作

  • 新增任務：點右上角「＋ 新增任務」或直接點擊象限空白區域
  • 編輯任務：hover 任務卡片 → 點✏ 編輯，或開啟詳情後點「編輯」
  • 移動象限：拖拉任務卡片到目標象限
  • 標記完成：點任務左側圓形勾選框，或在建議面板點「✓」
  • 恢復任務：在已完成區塊拖拉卡片到象限，或點「↩ 恢復」
  • 刪除任務：hover 卡片 → 點 ✕

標籤（Tags）

  • 編輯任務時可新增多個 Tag，點輸入框選現有 tag 或輸入新名稱
  • 建議執行面板上方會出現 tag filter 按鈕，可多選篩選
  • 當所有任務都不含某個 tag 時，該 filter 按鈕會自動消失

認領與協作

  • 認領任務：hover 卡片 → 點👤，或在建議面板點「接手」
  • 留言：點任務名稱開啟詳情側欄，在底部輸入留言
  • 愛心：點留言下方的 ♡ 對留言按讚，即時同步給所有人
  • 即時同步：所有操作透過 SSE 即時廣播，多人同時使用不衝突

建議執行順序

左側面板依「逾期 → 象限優先級（Q1→Q4）→ 截止日期」自動排序，幫助決定當前最應處理的任務。

已完成

  • 點 header「已完成」按鈕顯示 / 隱藏完成區塊
  • 依本週 / 上週 / 更早分組，點卡片可開啟詳情
  • 可拖拉已完成任務回象限恢復

關鍵字搜尋

  • Header 搜尋列即時搜尋任務標題、說明與留言內容
  • 符合的文字在卡片上以高亮色顯示
  • 點 ✕ 或清空輸入框可取消搜尋

分享連結

  • 每個任務都有獨立 URL（/:taskId），可直接連結到特定任務
  • 開啟詳情側欄後點「🔗」按鈕一鍵複製連結
  • 貼給隊友後對方開啟頁面會自動跳至該任務

請假公告

  • 右側面板「📅 請假公告」區點「＋ 請假」登記請假日期
  • 支援單日或起迄區間，可附備註說明
  • 過去的假期自動從清單中隱藏

火箭積分投票 🚀

  • 每週每人可投一票給表現最佳的隊友
  • 投票後觸發全屏慶祝動畫；火箭數累計顯示於右側排行榜
  • 每週一自動重置本週票數，歷史累計保留

週報 PPT 生成

  • 任務標記完成時可填寫說明並上傳截圖，作為週報素材
  • 點 header「週報」按鈕開啟設定 modal，可上傳 .pptx 版型模板
  • 點「生成 PPT」自動套用模板樣式，依人員與 Project 分組下載
  • 「清除歷史紀錄」可移除非本週的舊週報資料
